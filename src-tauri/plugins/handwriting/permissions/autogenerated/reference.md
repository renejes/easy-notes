## Default Permission

On-device handwriting recognition on iOS

#### This default permission set includes the following:

- `allow-recognize-handwriting`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`handwriting:allow-recognize-handwriting`

</td>
<td>

Enables the recognize_handwriting command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`handwriting:deny-recognize-handwriting`

</td>
<td>

Denies the recognize_handwriting command without any pre-configured scope.

</td>
</tr>
</table>

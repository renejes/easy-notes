## Default Permission

On-device handwriting recognition and PencilKit input on iOS

#### This default permission set includes the following:

- `allow-recognize-handwriting`
- `allow-ink-overlay-supported`
- `allow-attach-ink-overlay`
- `allow-update-ink-overlay`
- `allow-set-ink-tool`
- `allow-detach-ink-overlay`
